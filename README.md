## Installation
1. Download the latest release ZIP.
2. In Kodi, go to **Add-ons** > **Install from zip file**.
3. Select the downloaded file.

## Features
- High-quality Tamil and International movie scrapers.
- Fast and reliable link resolution.
- Branded "Freeland" experience.
