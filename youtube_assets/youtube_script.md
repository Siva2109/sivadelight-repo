# YouTube Script: How to Install SivaDelight on Kodi

## [Scene 1: Intro]
**(Visual: sivadelight_youtube_intro.png)**
"Welcome back to the channel! In today's video, I'm going to show you exactly how to install the SivaDelight addon on Kodi—the most powerful tool for high-quality Tamil and international content. Let's dive right in."

---

## [Scene 2: Prerequisites]
**(Visual: kodi_prerequisites_visual.png)**
"First things first, we need to make sure Kodi is ready. Open your Kodi settings, go to 'System', then 'Add-ons'. Make sure you enable 'Unknown Sources' and click 'Yes' on the warning. This allows us to install the SivaDelight repository."

---

## [Scene 3: Adding the Source]
**(Visual: kodi_add_source_visual.png)**
"Next, go back to the System screen and open 'File Manager'. Click on 'Add source'. Where it says '<None>', type in the official URL exactly as you see it on the screen: `https://raw.githubusercontent.com/Siva2109/sivadelight-repo/master/`. Give it a name like 'SivaRepo' and click 'OK'."

---

## [Scene 4: Installing the Repository]
**(Visual: kodi_install_steps_visual.png - Left Side)**
"Now, head back anyway to your Kodi Home screen. Click on 'Add-ons', then the 'Open Box' icon at the top left. Select 'Install from zip file'. Choose the 'SivaRepo' we just created and select the `repository.sivadelight-X.X.X.zip` file. Wait a second for the 'Siva Delight Repository installed' notification."

---

## [Scene 5: Installing the Add-on]
**(Visual: kodi_install_steps_visual.png - Right Side)**
"Finally, click on 'Install from repository'. Select the 'Siva Delight Repository', go to 'Video add-ons', and click on 'SivaDelight'. Hit 'Install', click 'OK' on any dependencies, and you're all set!"

---
